# Economy Coverage Map

Sixty-three sectors, grouped by position in the production chain rather than by industry label. Three are built. All three sit in trade and knowledge work — nothing yet touches extraction, production or public services, which is where the interface problems still unsolved are concentrated: telemetry, geospatial, scheduling, batch traceability.

Each sector carries its interface archetype rather than just a name. That line is the reason to build it — it says what the project will force you to solve.
